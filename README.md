# STARFALL — Touchscreen Shooter

A mobile-friendly arcade space shooter built with plain HTML, CSS, and JavaScript. No build tools or dependencies required.

## Play locally
Open `index.html` in a modern browser.

## Controls
- **Touch:** Use the left virtual stick to move and hold **FIRE** to shoot.
- **Keyboard:** WASD or arrow keys to move, Space to shoot, P to pause.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish the site. The game will be available at `https://weirdcheckout-bot.github.io/touchscreen-shooter/`.

## Features
- Responsive full-screen canvas
- Touch controls with pointer support
- Enemy waves and tougher enemies
- Score, hull/lives, and health pickups
- Particle effects and screen shake
- Pause, restart, and keyboard support
